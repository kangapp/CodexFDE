# 国家级一流本科课程申报级质量门（本地建设草案）

状态：本稿为本地维护新增的内部材料检查方案，不代表申报资格或课程认定。外部资格、正式批次和校方审核待校方确认；教学达成与改进效果待真实教学采集。来源为[建设方案](国家级一流本科课程建设方案.md)、[课程蓝图](课程蓝图.md)及仓库证据诚信约束，不是主管部门文件。

## 质量门对象

每份材料分别标记“已验证事实、建设计划、待补证”。记录事实来源、适用版本、核对人、日期和未覆盖部分。仓库代码、教材和参考实验只能支持其实际验证范围，不支持学校资格、真实学生效果或同行评价结论。

## 材料审核顺序

1. 合同一致性：逐项核对16讲标题和核心内容、演示结果、课内增量、通过标准；恢复的历史材料需记录Git版本并核对当前合同。
2. 教学设计：每讲将CLO、学生决策、活动和直接证据相互映射；ERP增量用于验证工作台能力，工作台增量回到实际ERP交付。
3. 工程真实性：核对两仓版本、真实执行、失败记录、修改范围、检查报告与业务状态；机器结果、证据完整性和具名人工决定分别表达。
4. 学习真实性：保留首次判断、失败和修订，以及同伴反馈和本人独立迁移；参考结果、AI建议和本地模拟不得代签学习证据。
5. 外部附件：培养方案、课程编码、学分学时、教学周期、团队资质、授权和知识产权逐项由实际责任部门提供；缺项写待校方确认或待建设。
6. 持续改进：用真实首次/二次提交变化、CLO表现和关键误区解释改进，不用满意度或平均分替代；效果待真实教学采集。

## 打回与补证

缺来源、候选版本错误、失败被覆盖、把模拟当真实或把绿灯当人审，均打回并保留原始记录。后续补证不覆写先前缺口；校方正式审核意见另行具名保存。文案完整、自动检查通过或图片存在，不表示附件真实或足以申报。

正式使用前核对当批次官方要求，注明口径与日期；尚未完成此核对时不生成资格或合规结论。未经授权的学生作品、敏感信息、密钥和运行数据库不得作为附件。通过当前本地材料结构检查，也只能说明教材基线可检查，不能声称已具备申报资格或已获得课程认定。
